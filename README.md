# 루티너 Routiner

사이트: https://judhjulie.github.io/routiner/

루틴을 만들고, 매일 체크하고, 기록과 리포트를 확인하는 웹 앱입니다. 홈 화면에 추가해 앱처럼 사용할 수 있습니다.

이 저장소는 GitHub Pages용 빌드 파일을 담습니다. main 브랜치의 루트 폴더를 배포합니다. 원본 React 프로젝트에서 `BASE_PATH=/routiner/ npm run build`를 실행한 뒤 web/dist의 내용을 교체하고 커밋하면 배포가 갱신됩니다.

개인 루틴 기록은 해당 브라우저에 저장되며 컴퓨터 간에 자동으로 공유되지 않습니다.
